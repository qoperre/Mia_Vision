## 발견 및 해결한 문제

1. Windows PowerShell 5.1이 네이티브 프로그램의 stderr 경고를 예외처럼 취급해 최초 CLI 출력 캡처가 중단됐습니다. 비치명적 토크나이저 경고였으며 캡처 방식을 수정해 정상 추론을 확인했습니다.
2. 기본 OCR 응답은 모든 문자를 맞췄지만 `63°C`를 `63℃`로 정규화하고 JSON 코드펜스를 추가했습니다. 프롬프트와 llama.cpp의 최상위 `json_schema` 제약을 적용해 원문 표기와 유효 JSON을 모두 확보했습니다.
3. 매 호출마다 모델을 다시 로드하는 CLI 대신 상주 `llama-server`를 사용해 실제 이미지 응답을 약 0.5~0.8초 수준으로 줄였습니다. 자연 이미지의 최초 입력은 이미지 크기와 캐시 상태에 따라 더 걸릴 수 있습니다.
